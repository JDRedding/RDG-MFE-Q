===========================  ENTROPY  =============================

Entropy = lost information when a system changes irreversibly.
In RDG terms: entropy is the projection of a single operator, 
R_discard.

-----------------------  CORE MAPPING  ---------------------------

A process f : X → Y discards some microstate detail.
The amount discarded = entropy increase.

    R_discard(f) = S(X) − S(Y)

This is the invariant behind all classical entropy formulas.

-----------------------  SID GEOMETRY  --------------------------

SID = microstate geometry (Ω = admissible microstates)

    S_SID ≈ k_B ln Ω

    Before: [ o o o o o o o o ]
    After : [ o o o o ]
    Entropy = ln(volume_before / volume_after)

Interpretation:
    • Irreversibility = shrinkage of admissible microstate volume
    • SID sees entropy as geometric loss

----------------------  PED PROBABILITY  ------------------------

PED = probability distribution flattening

    S_PED = −∑ p_i log p_i

    p = [0.8, 0.1, 0.1]  →  [0.33, 0.33, 0.33]
    Entropy = loss of sharpness in the distribution

Interpretation:
    • Flattening = more uncertainty
    • PED sees entropy as spread of probability mass

-------------------  Q THERMODYNAMICS  -------------------------

Q = reversible heat cost

    ΔS = ∫ (δQ_rev / T)

    [tight constraint] → [looser constraint] → [cannot return]

Interpretation:
    • Irreversible heat cost = irreversible information loss
    • Q sees entropy as the minimal reversible cost to undo f

Minimal algebraic definition of (R_discard)

In the cleanest form,  “relational discard” is loss of distinguishability
 under a coarse map (f : X to Y) between structured state spaces.

- State spaces and σ‑algebras

(X, F_X, mu_X), (Y, F_Y, mu_Y), f : X to Y

- Pushforward measure

mu_Y = f_\* mu_X, mu_Y(B) = mu_X(f^-1(B))

- Relational discard functional

R_discard(f)
  ;:=;
  S(mu_X) - S(mu_Y)

where (S) is an entropy functional appropriate to the stratum:

- SID: (S(mu) = k_B ln |Omega(mu)|)
- PED: (S(mu) = -sum_i p_i log p_i)
- Q: (S(mu) = int frac((delta Q_rev)/(T))

So in RDG shorthand:

R_discard(f)
  = S_SID(mu_X) - S_SID(mu_Y)
  = S_PED(mu_X) - S_PED(mu_Y)
  = S_Q(mu_X) - S_Q(mu_Y)

depending on which projection (pi_SID, pi_PED, pi_Q) choosen.

Equivalently, as a single invariant with projections:


S_SID = pi_SID circ R_discard, quad
S_PED = pi_PED circ R_discard, quad
S_Q = pi_Q circ R_discard.
