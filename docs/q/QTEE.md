### Axiom 1 — Irrational Containment

All irrational / irrelational residues live only in Q.

```
  (1)  forall x ( x in Q  -->  not-exists R  R(x) )
```

### Axiom 2 — Non-Inspection Principle

Nothing in the rational domain can look into Q.

```
  (2)  not-exists f ( f : S --> Q )
```

No map from S (or any SID/PED sort) into Q exists.

Q affects the rational world only via projection pi,
which outputs mediating interaction/dynamics — never Q itself.

```
  (3a)  pi : Q --> I x D

  (3b)  forall C_Q in Q,  exists (i,d)  such that  (i,d) = pi(C_Q)
```

pi is:
- non-invertible
- non-inspectable
- not definable inside any single sort

Any attempted dyad in S is unstable and must be repaired

No stable dyad exists without a Q-forced triad.

### Axiom 5 — Unified Boundary Condition

Q is a non-relational substrate whose only admissible effect
on the rational domain is to force triadic stabilizations via pi.

```
  Summary:

    * Every stable structure in QTEE is a surface projection of Q
```

## 7. Process — T_SID^explore+catalog

**Full name:** Exploration-dominant + Persistent Catalog update rule

### Configuration State

```
  C_t = ( S_t, I_t, D_t, T_t, Catalog_t )
```

The Catalog stores every explored triple with full metadata:

```
  entry format:  ( s, i, d, tau, reason, context, repair_history )
```

### Update Rule — Four Phases

```
  +---------------------------------------------------------------+
  | Phase 1: Heavy Exploration  (~70-80% of each cycle)           |
  |   * Generate new null points + candidate triples              |
  |   * Sample Catalog for re-mediation of overlooked items       |
  +---------------------------------------------------------------+
  | Phase 2: Mild Consistency Filtering                           |
  |   * Prune only clear malformations:                           |
  |     - dyadic collapse                                         |
  |     - arithmetic break                                        |
  |     - Q-violation                                             |
  |     - single-sort encoding                                    |
  |     - field instability                                       |
  +---------------------------------------------------------------+
  | Phase 3: Repair and Reintegration                             |
  |   * Repair malformed entries by adding mediating null points  |
  |     from the other triad side                                 |
  |   * Revalidate when new context makes entries coherent        |
  +---------------------------------------------------------------+
  | Phase 4: Catalog Update + Anti-Pattern Learning               |
  |   * Prioritize high-relevance unanswered questions            |
  |   * Record all repairs and failures as permanent data         |
  +---------------------------------------------------------------+
```

### Key Principles

- Malformations are **sacred data** — never discarded, always archived
- Repair is preferred over rejection
- The Catalog is append-only; pruning only removes from active consideration,
  never from the historical record
- Failed dyads and their residues are first-class entries
